# Кристалис — сайт стоматологии

Свёрстанная главная страница клиники. Чистый HTML/CSS/JS, без сборщика.

## Смотреть

Опубликованная версия: **https://panchishen.github.io/dental-ai/**

Деплой происходит автоматически при пуше в `main`, если менялось содержимое `site/`.

## Локальный запуск

```bash
node serve-site.js
```

Откроется на http://localhost:5055. Сервер отдаёт `site/` с `Cache-Control: no-store`,
поэтому правки css/js подхватываются простым обновлением страницы.

## Структура

| Путь | Что внутри |
| --- | --- |
| `site/index.html` | единственная главная страница |
| `site/css/app.css` | все стили |
| `site/js/app.js` | скрипты (переключатель вариантов Hero, слайдеры, формы) |
| `site/assets/` | изображения и видео |
| `claude-design-tokens/` | дизайн-токены и компоненты, синхронизированные с Figma |
| `Photos/` | исходные фотоматериалы |
| `serve-site.js` | статик-сервер для локальной разработки |

Договор с клиентом (`docs/`), исходные видеофайлы (`Video/`) и архив экспорта
из конструктора в репозиторий не попадают — см. `.gitignore`.
